# VibeSpec：stock-subgroups

## 1. Spec

### 目标

- 在现有 `leekFundView.stock` 股票树自定义分组下新增二级分组，形成“市场分类 → 一级分组 → 二级分组 → 股票”的最多两级自定义分组结构。
- 在每个分组节点最右侧展示该分组内股票的上涨数和下跌数。
- `A Stock` 行右侧提供统一展开、折叠其下全部分组的行内按钮；每个一级分组行右侧提供统一展开、折叠其二级分组的行内按钮；股票树标题栏不放置这两个按钮。

### 修改范围

- 现有无父级的自定义分组定义为一级分组；二级分组通过 `parentId` 关联同一市场内的一级分组。
- 一级分组可以同时包含直接归属股票和二级分组；展开一级分组时先展示二级分组，再展示直接归属股票。
- 二级分组只能创建在一级分组下，不允许继续创建三级分组。
- 一级分组行统计自身直接归属股票及全部二级分组股票，股票代码去重后计算上涨数和下跌数。
- 二级分组行、自定义分组行和内置分组行都在 TreeView `description` 区域展示 `涨N 跌N`；涨跌幅等于 0、停牌或无有效涨跌幅的股票不计入上涨或下跌。
- 从股票右键 `选择分组` 时同时展示一级分组和二级分组，并标明层级路径；股票仍只归属一个自定义分组。
- 用户可在一级分组右键创建二级分组；同一父分组下二级分组名称不能重复。
- 分组重命名、上移、下移、置顶、置底同时支持一级和二级分组；排序只在同一市场、同一父级的兄弟分组之间进行。
- 分组拖拽排序同时支持一级和二级分组；只允许在同一市场、同一父级的兄弟分组之间调整顺序，不通过拖拽改变父级。
- 股票可拖入一级分组或二级分组并在对应分组内排序；从关注分组发起的拖拽仍只调整关注顺序。
- 删除二级分组只删除该二级分组配置；删除一级分组时同时删除其二级分组配置。两种删除都不从 `leek-fund.stocks` 删除股票。
- `持仓股`、`关注`、`未分组` 仍是市场分类下的内置分组，不参与两级自定义分组结构。
- `leek-fund.stockGroups` 作为唯一分组配置，结构增加可选 `parentId`；无 `parentId` 表示一级分组，有 `parentId` 表示二级分组。
- 股票树根部只展示 A 股市场节点和有数据时的“不支持股票”节点，不再展示独立 ETF、港股、美股市场节点。
- ETF 配置、行情获取和数据解析能力保持不变；ETF 股票按 `sh`、`sz` 代码归入 A 股市场节点下的内置分组或自定义分组，A 股节点数量包含 ETF 数量。
- 股票树标题栏创建自定义分组时固定创建 A 股分组，不再提供港股、美股分组入口；已有港股、美股股票和分组配置不做数据删除。
- `A Stock` 行右侧 `展开下级分组` 同时展开该市场节点下的内置、一级、二级分组；`折叠下级分组` 同时折叠上述节点。
- 一级分组行右侧 `展开下级分组` 和 `折叠下级分组` 同时控制当前一级分组自身及其直接二级分组：展开时两层全部展开，折叠时一级自身和二级全部折叠，不影响其他一级分组。
- 通过 TreeView 展开、折叠事件按节点 ID 记录当前运行期间的市场及自定义分组状态；行情刷新、分组重命名和分组排序不得重置该状态。
- 批量展开、折叠命令修改状态后必须递增可折叠节点的 TreeItem 身份版本再刷新，强制原生 TreeView 按目标 `collapsibleState` 重建节点，不能只刷新同 ID 节点。

### 非目标范围

- 不支持三级及更深层级分组。
- 不在二级分组上新增批量展开、折叠命令；二级分组仅保留原生箭头。
- 不把展开、折叠状态写入用户配置或扩展持久化状态；扩展重新启动后按默认状态展示。
- 不新增独立分组管理页面，不把股票树改造成 Webview。
- 不支持通过拖拽把一级分组变成二级分组、把二级分组移动到其他一级分组或提升为一级分组。
- 不迁移股票到二级分组；已有一级分组及其股票归属保持不变。
- 不改变持仓、关注、未分组的状态与排序规则。
- 不修改行情数据源、股票详情、策略中心、状态栏、价格提醒、新闻或其他非股票树功能。
- 不删除 ETF 配置、ETF 行情请求和 ETF 解析逻辑；不清空已有港股、美股股票及分组配置。
- 不新增依赖，不修改 lock 文件，不做无关重构、目录迁移或大面积格式化。
- 不做未说明的兼容分支、兜底或降级逻辑。
- 不自动 commit、push、merge。

### 验收标准

1. 一级自定义分组右键可创建二级分组，二级分组展示在对应一级分组下，且不能继续创建三级分组。
2. 二级分组名称不能为空，同一父分组下不能重名；不同一级分组下允许同名二级分组。
3. 一级分组展开后先展示二级分组，再展示直接归属该一级分组的股票；二级分组展开后展示其归属股票。
4. 股票右键 `选择分组` 可选择一级或二级分组，选项能清楚表达“一级 / 二级”路径，选中后股票只保留在目标自定义分组。
5. 股票可拖入同市场的一级或二级分组，并可在目标分组内调整顺序；跨市场拖拽仍被拒绝。
6. 一级分组和二级分组只能在同父级兄弟范围内通过右键命令或拖拽排序；拖拽不改变分组层级或父级。
7. 删除二级分组不会删除股票；删除一级分组会一并删除其二级分组配置，但不会删除股票，相关股票转为未分组展示。
8. 一级分组重命名只校验同市场一级分组重名，二级分组重命名只校验同父级兄弟分组重名。
9. 每个内置或自定义分组行最右侧显示 `涨N 跌N`；上涨、下跌按当前行情 `percent > 0` 和 `percent < 0` 统计。
10. 一级分组的涨跌数覆盖该一级分组直接股票和所有二级分组股票，且同一股票代码只统计一次；二级和内置分组只统计自身当前展示股票。
11. 现有未设置 `parentId` 的分组仍作为一级分组读取，不需要数据迁移；保存后配置结构保持单一 `StockGroupConfig` 模型。
12. 关注列表拖拽、持仓叠加、未分组计算和同股票多节点上下文不被破坏。
13. 未新增依赖、未修改 lock 文件，TypeScript 编译通过或明确记录失败原因。
14. `A Stock` 行右侧显示展开和折叠按钮，一次操作覆盖 A 股市场节点下的内置分组及所有一级、二级自定义分组；股票树标题栏不显示这两个按钮。
15. 每个一级分组行右侧显示展开和折叠按钮；展开时当前一级自身及其二级全部展开，折叠时当前一级自身及其二级全部折叠，不影响其他一级分组；没有二级分组但包含直属股票时，一级自身仍可折叠、展开。
16. 二级分组不展示批量展开、折叠菜单，仍可通过原生箭头单独展开、折叠。
17. 批量操作后发生行情定时刷新、手动刷新、分组重命名或分组排序时，相关节点保持操作后的状态。
18. 股票树根部不再出现 ETF、港股、美股市场节点，只保留 A 股节点和有数据时的“不支持股票”节点。
19. ETF 行情仍正常获取并显示在 A 股节点下；A 股根节点数量和涨跌统计包含 ETF。
20. 从股票树标题栏创建分组时直接创建 A 股一级分组，不再出现港股、美股分组选项；已有港股、美股配置不被删除。
21. 点击 `A Stock` 或一级分组行右侧的展开、折叠按钮后，原生 TreeView 立即产生对应视觉变化，不继续沿用命令执行前的同 ID 节点状态。

## 3. Review Report

### 最终结论

结论：需人工确认。

原因：功能、编译、定向逻辑断言和 VSIX 打包均已完成，未发现需继续修复的代码问题；但本次修改 `package.json` 命令/菜单清单及用户可导入导出的 `leek-fund.stockGroups` 配置对象结构，属于项目约定的高风险修改，且原生 TreeView 的真实右键与拖拽体验仍需人工确认。

### Spec 与验收标准检查

- 已使用单一 `StockGroupConfig` 模型增加可选 `parentId`：无父级为一级分组，有父级为二级分组；读取时只接受同市场一级父分组，不支持三级关系。
- 一级分组 children 固定为“二级分组节点在前、一级直属股票在后”；二级分组 children 只包含本组股票。
- 一级分组涨跌统计覆盖直属股票及所有二级分组股票并按代码去重；二级分组和内置分组统计当前分组直接展示股票，统一显示 `涨N 跌N`。
- 一级分组右键新增 `创建二级分组`；名称校验按同一父级执行。二级分组没有创建下级菜单，无法继续创建三级分组。

- `A Stock` 行和一级分组行右侧已提供展开/折叠下级按钮；股票树标题栏、二级分组和“不支持股票”行不展示这些按钮。

- 关注列表拖拽仍优先进入关注私有状态分支并直接返回，没有进入自定义分组写入链路。
