# VibeSpec：hermes-desktop-plugin

## 1. Spec

### 目标

- 将当前项目改造为可安装到 Hermes Desktop 的本地插件。
- 在 Hermes Desktop 左侧注册一个 `LeekFund` 股票树 Pane，视觉结构和核心交互与当前 VS Code 股票树保持一致。
- 股票树只展示 A 股市场分类，并固定按 `持仓股`、`关注`、`未分组`、自定义分组展示；已同步的港股、美股数据保留在本地状态中但不在界面展示。
- 一级、二级自定义分组保留父子关系，二级分组在视觉上相对一级分组缩进。
- 股票右键菜单只保留一个“移动到…”入口，移动目标使用默认折叠的树形结构选择，不一次性平铺全部分组。
- 一级分组中的股票条目相对分组标题缩进，二级分组中的股票条目在此基础上再增加一级缩进。
- 每个分组名称后展示该分组全部股票的上涨、下跌和平盘数量；一级父分组汇总其直接股票和所有二级子分组股票。
- 股票在其真实所属分组或未分组列表中支持拖动排序，并可拖入同市场其他真实分组。
- 持仓和关注叠加视图分别支持独立拖动排序；只调整各自列表顺序，不改变股票真实分组或持仓、关注标记。
- 一级、二级自定义分组分别支持在同级范围内拖动排序，拖动排序不改变父子层级。
- 股票或分组拖动成功后不弹出成功提示，失败时仍显示错误提示。
- 股票条目展示股票名称、股票代码、涨跌幅和当前价格。
- 添加股票时支持按 A 股股票代码或中文名称查询并选择结果。
- 股票查询结果使用固定高度的滚动区域，搜索框和弹窗高度不随结果数量变化。
- A 股行情按国内市场习惯展示：上涨为红色，下跌为绿色。
- 红绿行情色降低视觉强度，保留方向辨识度但不抢占股票名称和分组信息的视觉焦点。
- 在 Hermes Desktop 底部状态栏同时平铺全部固定指数和用户选择的股票，不再轮播。
- 行情请求由 Hermes 本地 Python 后端执行，Desktop 页面通过插件私有 REST 命名空间读取数据。
- 支持将当前 VS Code LeekFund 插件的自选股票、一级/二级分组、持仓、关注和状态栏股票一次性同步到 Hermes。

### 修改范围

- 新增 Hermes 通用插件清单和注册入口。
- 新增 Hermes Dashboard 插件后端，仅提供 Desktop 插件调用的私有 REST API，不注册 Web Dashboard 页面。
- 新增单文件 Hermes Desktop ESM 插件，注册左侧 Pane 和状态栏。
- 新增本地 JSON 状态，保存股票全集、自定义分组、持仓标记、关注标记及状态栏自选股票。
- 复用当前项目已使用的新浪行情接口及字段语义，不新增行情数据源。
- 复用当前 VS Code 插件已使用的腾讯股票联想接口提供名称和代码查询，只返回沪、深、北交易所 A 股结果。
- 新增 Hermes 插件安装脚本，将后端和 Desktop 文件安装到当前 Hermes Home。
- 新增显式数据同步脚本，只读访问 VS Code 用户设置和扩展 `globalState`，写入前备份现有 Hermes 插件状态。
- Hermes 股票树状态支持 VS Code 当前使用的两级自定义分组。
- 新增后端单元测试和 Desktop 文件静态校验。

### 非目标范围

- 不实现右侧内容区。
- 不实现股票详情、K 线、技术指标或交易明细。
- 不实现策略中心、持仓成本管理、推荐 A 股、价格提醒或定时任务。
- 不实现 Hermes Skill、模型工具、Slash Command 或 Web Dashboard 页面。
- 不接入券商、交易、下单、撤单或资金能力。
- 不新增行情数据源；腾讯接口只用于搜索候选股票，不用于行情展示。
- 不实现 VS Code 与 Hermes 的持续、双向或自动同步。
- 不迁移推荐股票、策略中心、持仓成本、提醒条件或其他 Hermes 当前没有对应功能的数据。
- 不修改 VS Code 用户设置、扩展 `globalState` 或数据库。
- 本轮不删除当前 VS Code 代码，不维护 VS Code 与 Hermes 之间的运行时兼容层。
- 不新增第三方依赖，不修改 `package.json` 或 lock 文件。
- 不通过拖动创建、解除或改变分组父子关系，不允许跨市场拖动股票。
- 不自动 commit、push 或 merge。

### 验收标准

1. Hermes Desktop 能发现 `leek-fund` Desktop 插件，并注册一个默认位于左侧、宽度约 300px 的股票树 Pane。
2. 股票树只展示 A 股分类且可展开和折叠；港股、美股状态数据不删除但不出现在界面。
3. 每个市场分类下按 `持仓股`、`关注`、`未分组`、自定义分组顺序展示。
4. 股票条目能看到名称、股票代码、涨跌幅和当前价格。
5. 用户能在股票树内按股票代码或中文名称查询 A 股并选择添加，也能删除股票。
6. 用户能创建、重命名、删除自定义分组，并将股票移动到同市场分组或移回未分组。
7. 用户能切换持仓、关注状态；持仓和关注是叠加展示，不改变股票原分组。
8. Desktop 插件按不低于 5 秒的间隔通过 `ctx.rest` 刷新行情，不直接从渲染进程请求行情接口。
9. Hermes Desktop 状态栏同时平铺全部固定指数和用户配置的股票，不轮播、不依赖点击切换。
10. 行情接口失败时，后端返回结构化错误，股票树保留上一次数据并显示可理解的错误状态。
11. 插件状态保存到 Hermes Home 的插件数据目录，Hermes 重启后仍可读取。
12. 安装脚本能将后端安装到 `$HERMES_HOME/plugins/leek-fund`，将 Desktop 文件安装到 `$HERMES_HOME/desktop-plugins/leek-fund/plugin.js`。
13. 未新增第三方依赖，未修改当前 VS Code 运行逻辑，自动化验证通过或明确记录失败原因。
14. 同步脚本能从 VS Code 用户设置读取 `leek-fund.stocks`、`leek-fund.stockGroups` 和 `leek-fund.statusBarStock`。
15. 同步脚本能从扩展 `globalState` 读取持仓和关注代码，不读取或迁移策略私有状态。
16. 同步后保留合法的一级/二级分组关系，只迁移当前自选股票范围内的分组、持仓、关注和状态栏代码。
17. 写入 Hermes 前生成原状态备份；VS Code 原始数据保持不变。
18. 同步后的真实 Hermes Desktop 左侧股票树和状态栏能显示迁移结果。
19. 二级自定义分组相对一级分组有明确的横向缩进，层级关系可直接辨认。
20. 股票查询只返回 A 股候选项，查询失败时显示可理解的错误且不影响现有股票树。
21. 股票右键菜单不平铺全部移动目标，只显示一个“移动到…”入口；进入后以默认折叠的树形结构展示一级和二级分组。
22. 二级分组中的股票条目相对一级分组股票有明确的额外缩进。
23. 股票查询结果区固定高度并可滚动，输入框和弹窗高度不随查询结果数量变化。
24. 股票树和状态栏中上涨行情显示为红色，下跌行情显示为绿色，平盘或无行情保持中性色。
25. 股票树和状态栏的红绿行情数字使用较低视觉强度，不影响方向辨识且不比股票名称更突出。
26. 一级分组中的股票条目相对分组标题有明确缩进，二级分组股票比一级分组股票再多一级缩进。
27. 分组名称后按 `↑上涨数 ↓下跌数 =平盘数` 展示组内股票行情；一级父分组统计范围包含其直接股票及所有二级子分组股票，重复代码只统计一次。
28. 未分组和自定义分组中的股票可通过拖动调整顺序；拖到另一真实分组标题或股票位置时完成同市场跨分组移动并保存目标位置。
29. 持仓和关注列表中的股票可分别独立拖动排序；排序不改变股票真实分组、持仓标记、关注标记和状态栏标记，也不能在持仓、关注与真实分组之间通过拖动移动。
30. 自定义分组可在同一市场、同一父分组下拖动排序；一级和二级分组不能互相改变层级，也不能与内置分组排序。
31. 股票和分组拖动后的顺序写入 Hermes 插件状态，刷新快照和重启 Hermes 后保持不变。
32. 股票和分组拖动成功后不显示成功提示；拖动请求失败时仍显示错误提示。
33. 分组落点位置必须在原生 `drop` 事件处理期间同步计算，异步排序请求不得继续读取已释放的事件对象。

实现只包含左侧 A 股股票树和状态栏指数平铺的 Hermes Desktop 插件，并将当前 VS Code 对应数据一次性同步到 Hermes；本轮修复分组拖动异步读取已释放事件对象导致的失败。

- `specs/hermes-desktop-plugin.md`
