# DSH 插件发布

## Spec
目标：使 DSH 插件可从源码构建、打包和安装，发布版本并申请收录。
范围：DSH 插件构建依赖、类型、包元数据及发布文档；收录仓库的一条条目。
非目标：改动行情业务、数据格式、其他扩展、既有默认分支内容或引入运行时降级。
验收：正式构建与现有测试通过；安装包包含入口、类型和 bundle patch；发布物与公开源码版本一致；收录 YAML 符合官方规范。
