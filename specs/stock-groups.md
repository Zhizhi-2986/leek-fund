# VibeSpec：stock-groups

## 1. Spec

### 目标

- 在 VS Code 左侧 `leekFundView.stock` 股票树列表中补充显示股票代码。
- 在原生 TreeView 能力范围内，让每只股票呈现“名称 + 股票代码”和“行情摘要”两层信息表达。
- 新增股票分组功能，用户可以创建分组，并通过右键菜单调整分组顺序或删除分组。
- 新增股票树内置 `持仓股` 分组，并让 `持仓股`、`未分组` 固定展示在自定义分组上方。
- 支持在分组内展示股票，分组节点可展开和折叠。

### 修改范围

- 股票列表入口限定为当前项目已有的 VS Code 左侧 `leekFundView.stock` TreeView。
- 保留现有市场一级分类：A 股、港股、美股、接口不支持股票。
- 自定义分组只作用于 A 股、港股、美股三个市场分类下，不作用于接口不支持股票。
- 新增已注册配置项 `leek-fund.stockGroups`，用于保存用户创建的分组及分组内股票顺序。
- `leek-fund.stocks` 继续作为股票全集和未分组股票顺序来源。
- 新增扩展私有状态 `leek-fund.stockTreeHoldingCodes`，仅用于保存股票树内的持仓标记，不写入 VS Code 用户设置。
- 市场分类下固定展示顺序为：`持仓股`、`未分组`、自定义分组。
- `持仓股` 和 `未分组` 是内置分组，不参与自定义分组排序，不写入 `leek-fund.stockGroups`。
- 用户通过股票树标题或市场分类右键命令创建分组。
- 用户可通过分组右键菜单调整同一市场分类内的分组顺序。
- 用户可通过分组右键菜单删除自定义分组；删除分组只删除分组配置，不删除组内股票。
- 用户可通过股票右键菜单选择该股票所属自定义分组，或选择 `未分组` 移出自定义分组。
- 用户可通过股票右键命令切换持仓状态；标记持仓后股票额外展示在 `持仓股` 分组，同时保留在原自定义分组或未分组中。
- 用户可拖动股票进入分组、在分组内调整顺序，或拖回市场分类/未分组节点。
- 股票条目补充股票代码，并保留现有涨跌幅、现价等行情摘要展示。

### 非目标范围

- 不把股票列表改造为 Webview。
- 不新增独立股票管理页面。
- 不新增分组重命名、批量管理能力。
- 不再通过拖拽调整分组顺序。
- 不通过拖拽切换持仓状态。
- 不把股票树持仓标记改造成策略中心正式持仓，不新增成本、数量、收益、止损或目标价管理。
- 不新增股票数据源，不修改行情请求接口。
- 不修改股票详情、策略中心、状态栏轮播、价格提醒、新闻或其他非股票树功能。
- 不修改数据库结构、权限认证、登录鉴权、加密逻辑、CI/CD、构建部署脚本、环境变量或生产配置。
- 不新增依赖，不修改 lock 文件，不做无关重构、目录迁移或大面积格式化。
- 不做未说明的兼容分支、兜底或降级逻辑。

### 验收标准

1. 股票树中的股票条目能直接看到股票名称、股票代码、涨跌幅和当前价格。
2. 创建分组命令可在股票树标题或市场分类右键入口触发。
3. 用户创建分组时必须选择或继承所属市场分类，分组名称不能为空，且同一市场分类下分组名不能重复。
4. 每个支持的市场分类下默认固定展示 `持仓股` 和 `未分组`，且 `持仓股` 始终在 `未分组` 上方。
5. 自定义分组展示在内置分组下方，分组节点可展开和折叠。
6. 用户可在同一市场分类内通过分组右键菜单执行上移、下移、置顶、置底调整自定义分组顺序，内置分组不参与排序。
7. 用户可通过分组右键菜单删除自定义分组；删除后组内股票不从 `leek-fund.stocks` 中删除，按原股票状态继续显示在 `未分组` 或 `持仓股` 中。
8. 用户可通过股票右键菜单执行 `选择分组`，只能选择该股票所属市场分类下的自定义分组，或选择 `未分组` 移出自定义分组。
9. 用户可通过股票右键命令切换持仓状态；标记持仓后股票展示在所属市场的 `持仓股` 分组，同时保留在原自定义分组或未分组中。
10. 用户可拖动同一市场分类内的股票进入自定义分组、在分组内调整顺序，或移动到未分组区域；拖动到 `持仓股` 不修改分组配置。
11. 禁止跨市场分类拖动股票；分组排序命令只调整同一市场分类内的自定义分组，不修改其他市场分类的分组相对顺序。
12. 删除股票后，该股票不再残留在任何分组配置中。
13. 未修改非目标范围内的功能，未新增依赖，自动化验证至少通过 TypeScript 编译或明确记录失败原因。
