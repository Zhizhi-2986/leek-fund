# VibeSpec：分组展开时不展开子分组

## 1. Spec

### 目标

解决展开分组时，子分组（一级、二级）也跟随展开的问题。确保展开父分组时，子分组默认保持折叠状态，需要手动逐个展开。

### 修改范围

- `src/explorer/stockProvider.ts`

### 非目标范围

- 不修改其他 UI 行为
- 不修改拖拽排序逻辑

### 验收标准

1. ✅ 展开任意分组时，其子分组保持折叠状态
2. 折叠父分组时，不影响子分组的展开状态
3. 手动展开子分组后，状态应该被记住
