# VibeSpec：speed-ranking-and-minute-enhance

## 1. Spec

### 目标

- 涨速榜剔除 ST 类股票与北交所股票：榜单只保留沪深两市主板、中小板、创业板、科创板的非 ST A 股。
- 分时悬浮窗增强：在现有分时卡片中新增当日分时均价线，分时图纵轴以涨停价、跌停价为上下边界并在图上标注涨停、跌停数值与百分比；悬浮窗背景不透明。
- 分时图不再展示“最新时间”，右下角展示 5 日、10 日、20 日均线（MA5/MA10/MA20）。
- 涨速榜每条记录新增“添加股票”按钮，点击后添加到自选并默认进入“关注”分组；已添加的记录显示已添加状态。
- 涨速榜左侧面板标题由“涨速榜”改为“行情排行”；面板内通过 Tab 切换“涨速榜 / 涨幅榜 / 跌幅榜”三个榜单，默认展示涨速榜，每条记录仍有添加按钮；行情排行的个股记录鼠标悬浮时同样展示分时悬浮窗。
- 删除“未分组”分组逻辑：股票树不再显示“未分组”分组；添加股票时默认添加到“关注”分组；现有未分组的 A 股自动迁移到“关注”分组。
- 分组逻辑恢复为：持仓分组在关注分组上方，关注分组作为叠加层标记可与其他自定义分组共存（股票可在关注与其他分组重复显示）；持仓、关注均为独立叠加层。
- 股票树分组折叠状态持久化：市场分类与分组的展开/折叠状态通过 `ctx.storage` 保存，重启 Hermes Desktop 后保留。
- 行情排行新增“策略选股”Tab：展示策略分组（先 demo 两个策略：“涨停聚焦”、“放量上攻”），策略结果复用榜单行样式（含添加股票、hover 分时）。

### 修改范围

- `dashboard/plugin_api.py`：
  - 涨速榜：`_eastmoney_a_share_code` 不再映射北交所代码，`parse_speed_ranking` 剔除名称含 ST 的股票；榜单数据源：涨速榜改用腾讯排行接口（`proxy.finance.qq.com` 的 `sort_type=speed`，东财作为 fallback），涨幅/跌幅榜改用新浪沪深排行接口（`changepercent` 排序）；`get_ranking` 为每条记录标记是否已在自选（`added`）及所在一级分组，并按类型分别缓存。
  - 分时：`_tencent_quote_detail` 新增涨停价（field 47）、跌停价（field 48）字段；`get_a_minute_line` 为每个分时点计算均价，返回涨停价、跌停价、最高、最低，并通过腾讯日 K 接口计算返回 `ma5`、`ma10`、`ma20`。
  - 分组：`BUILTIN_GROUPS` 去掉“未分组”且顺序调整为“关注”在前；`build_categories` 不再生成未分组分组；`normalize_state` 将未分组 A 股自动迁移到 `watch_codes`，并剔除与自定义分组重复的关注股票（互斥）；`add_stock` 默认同时写入 `watch_codes`；`move_stock` 清理“未分组”分支、支持移动至“关注”，移到自定义分组时同步从关注移除；`reorder_stock` 清理“未分组”分支。
- `desktop/plugin.js`：
  - 分时悬浮窗：背景改为实底不透明；移除“最新时间”，底部行右下角展示 MA5/MA10/MA20；SVG 中新增均价线，纵轴以涨停/跌停为边界并在图上标注；价格行展示最新均价。
  - 行情排行面板：标题改为“行情排行”，Tab 切换涨速/涨幅/跌幅三榜；每条记录新增添加按钮，已添加显示“已添加”；移动股票对话框去掉“未分组”、新增“关注”选项；股票树市场/分组折叠状态通过 `ctx.storage` 持久化。
- `tests/hermes/test_plugin_api.py`：
  - 更新涨速榜北交所/ST/回退断言；新增 `added` 标记断言；更新分组迁移、默认关注、移动/排序语义断言；更新分时 MA 与字段断言。
- 维护本 Spec 文件。

### 非目标范围

- 不修改状态模型字段结构，不修改 `package.json`、lock 文件或构建配置。
- 不新增第三方依赖；日 K 均线复用腾讯日 K 接口（与现有腾讯行情链路同源）。
- 不改动持仓（holding）叠加层与状态栏逻辑。
- 不自动 commit、push 或 merge。

### 验收标准

1. 涨速榜结果中不含任何北交所（`bj`）股票，股票代码前缀仅剩 `sh`、`sz`。
2. 涨速榜结果中不含名称含 `ST`（含 `*ST`、`ST`、`SST` 等，大小写不敏感）的股票。
3. 涨速榜仍严格按涨速降序截取前 20 条，排序与条数限制不变；实时节点不可达时自动使用延迟节点。
4. 涨速榜每条记录包含 `added` 字段，标识该股票是否已加入自选。
5. 分时接口返回每个分时点的 `avg_price`（均价），规则为 `累计成交额 /（累计成交量 × 100）`，成交量无效时该点均价为 `None`。
6. 分时接口返回 `limit_up`、`limit_down`、`high`、`low`、`ma5`、`ma10`、`ma20` 字段，均来自腾讯接口。
7. 分时图纵轴最大值对应涨停价、最小值对应跌停价（无效时回退价格范围）；均价线（黄色）、价格线、昨收线可区分；图上标注涨停、跌停的数值与百分比；横坐标固定为交易时间轴（9:30-11:30 与 13:00-15:00，午休时段连接），不按数据点数自动撑满。
8. 分时悬浮窗背景不透明；不展示最新时间；底部行右下角展示 `MA5`、`MA10`、`MA20` 数值；价格行展示最新均价。
9. 股票树不再显示“未分组”分组；添加股票默认进入“关注”分组；历史未分组 A 股迁移到“关注”。
10. 行情排行的个股记录鼠标悬浮（延迟 300ms）时展示分时悬浮窗，滚动榜单时关闭，与股票树悬浮行为一致。
11. 关注分组默认排在最前，与自定义分组股票互斥不重复；持仓为独立叠加标记可与其他分组共存。
10. 未新增依赖，未修改 `package.json`、lock 文件和现有 VS Code 运行逻辑。
11. Python 单元测试、Python 语法检查、Desktop JavaScript 语法检查和 `git diff --check` 通过。
