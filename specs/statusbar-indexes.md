# VibeSpec：statusbar-indexes

## 1. Spec

### 目标

- 在 VS Code 底部状态栏指数区域新增日本、韩国指数展示。
- 复用现有状态栏指数展示方式，显示指数名称、现价、涨跌幅，并保留 tooltip 行情摘要。

### 修改范围

- 仅修改现有 `src/statusbar/statusBar.ts` 的状态栏指数代码列表和指数数据解析逻辑。
- 日本指数使用现有新浪行情接口可返回数据的日本指数代码。
- 韩国指数使用现有新浪行情接口可返回数据的韩国 KOSPI 指数代码。
- 保留现有中国指数展示和刷新逻辑。

### 非目标范围

- 不新增数据源。
- 不新增配置项或设置页面。
- 不修改股票树、分组、持仓标记、策略中心、价格提醒、新闻或股票状态栏轮播逻辑。
- 不修改 package.json、lock 文件、构建脚本、CI/CD 或生产配置。
- 不新增依赖，不做无关重构、大面积格式化或目录迁移。

### 验收标准

1. 状态栏指数默认列表包含日本指数和韩国 KOSPI 指数。
2. 现有 A 股指数仍按原格式解析和展示。
3. 新增日本、韩国指数能从新浪接口响应中解析名称、现价、涨跌、涨跌幅和更新时间；接口缺失的字段使用可解释的默认值，不影响状态栏渲染。
4. `hideStatusBar`、`hideStatusBarIcon`、涨跌颜色和状态栏刷新行为保持不变。
5. 未新增依赖，自动化验证至少通过 TypeScript 编译或明确记录失败原因。

### 风险检查

风险等级：中。

风险项：

- 日本、韩国指数来自现有新浪行情接口；如果接口临时返回空值，状态栏会过滤该指数，不影响其他指数展示。
- 境外指数返回字段与 A 股指数不同，本次对缺失字段使用现价、推导昨收或空更新时间补齐 tooltip 字段；真实字段含义仍需在 VS Code 状态栏视觉上确认。
- `int_nikkei` 属于简单境外指数格式，仅有名称、现价、涨跌、涨跌幅四个字段，因此 tooltip 中最高、最低、今开会使用现价补齐。
- 状态栏指数是固定列表，暂不提供用户配置入口。

### 测试与验证

已执行验证：

- 新浪接口探测：带 `Referer: http://finance.sina.com.cn/` 请求后，`int_nikkei` 和 `b_KOSPI` 均有返回数据。
- `npm run compile`：通过；`postcompile` 子项目构建通过，保留既有 `import/no-anonymous-default-export` warning。
- `git diff --check`：通过。

未覆盖风险：
